### 🤖 AI Incident Remediation System (LangGraph + Local LLMs)

Built an AI-powered incident analysis and remediation system that processes infrastructure failure signals, diagnoses root causes, and generates actionable fixes such as Bash scripts and Terraform recommendations.

The project simulates a real-world SRE workflow using an LLM-driven LangGraph pipeline that transforms raw incident logs into structured remediation plans.

**Key Activities:**

- Designed a multi-step LangGraph workflow for incident → diagnosis → remediation processing
- Integrated a local LLM (Ollama) for offline inference and root cause analysis
- Implemented structured incident parsing from logs and system signals
- Generated automated remediation outputs including Bash scripts and infrastructure suggestions
- Simulated production-style incident handling with severity classification and fix recommendations
- Designed for future integration with pgvector for incident memory and similarity search

**Technologies:** Python • LangGraph • Ollama • Docker • NGINX • PostgreSQL (pgvector) • Linux • WSL2
